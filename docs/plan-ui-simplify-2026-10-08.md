# 일반 사용자 화면 단순화 계획 (2026-10-08)

상태: **스케치 승인 대기** (코드 변경 없음). 근거: 2026-10-08 현황 조사.

## 1. 현황 (일반 사용자 기준)

- 화면 21개가 네 곳에 나온다: 하단 시트 탭 6개 / 상단 리본 21개 / 전체 메뉴 서랍·검색 21개 / 홈 카드·길잡이.
- 시트 6개(홈·포트폴리오·모아가기·시드 만들기·목표 트래커·시장)는 리본 '홈' 탭에 그대로 또 들어 있다.
- 리본 5탭 중 '시장 공부'(뉴스 1개)·'직접 주문'(2개)은 사실상 빈 탭이고, '홈' 탭 하나가 12개를 진다.
- 글이 많은 화면: 계획 점검(약 2.8만 자), 돈 흐름(약 2.2만), 시드 만들기(약 1.7만), 포트폴리오(약 1.2만). 한글 문구 글자 수를 코드에서 센 대략값.
- 원인: 메뉴 뼈대가 옛 종목 선별 흐름(`FLOW_STEPS` 1~7)이 기준인데, 9/29 이후 제품 방향(지수 정기매수 + 행동 실수 차단)에 새 기능을 '홈'에 계속 얹었다.

## 2. 목표

사용자가 **경험 → 검증 → 따라하기 → 성장** 순서로 길을 잃지 않게 한다. 한 화면은 한 곳에서만 열린다(서랍·검색은 "전부 찾기"용 예외).

## 3. 스케치 (일반 사용자)

시트 = 지금 내가 어느 단계인가 (하단, 단계당 대표 화면 1개)
리본 = 그 단계에서 쓰는 도구 (대표 화면은 리본에서 뺀다)

```
시트(하단)   홈 | 모으기 | 계획 | 내 계좌 | 더 보기
             └ 대시보드   └ 모아가기   └ 목표 트래커   └ 포트폴리오

리본 탭      홈        : 처음 설정 다시 하기, 시장, 뉴스
             모으기    : 돈 흐름, 시드 만들기, 따라 사기
             계획      : 계획 점검, 섞어보기, 리밸런싱 가이드, 시뮬레이터, 실행가이드
             내 계좌   : 거래기록, 내 선택 돌아보기
             가족      : 자녀 계좌, 부부 연결        (연결 안 했으면 접힘)
             설정      : 설정, 프로필
```

- 화면 21개 중 시트 대표 4개는 리본에서 제외 → 리본 17개. 서랍 '전체 메뉴'는 유지.
- '직접 주문'·'시장 공부' 탭 폐지. 시뮬레이터·실행가이드는 '계획'의 도구로 이동.
- 종목 선별 흐름(`FLOW_STEPS` 번호 1~7)은 관리자 전용으로 둔다. 일반 사용자 화면에는 번호·단계 표기가 이미 없음.
- 관리자 메뉴는 이번 범위에서 건드리지 않는다.

## 4. 단계 (각각 빌드 가능한 커밋)

1. **메뉴 정의 정리** — `web/src/navigation.ts`의 `MENU_SECTIONS`/`SHEET_NAV_KEYS` 재배치, 중복 제거. 단위 테스트(시트 키가 리본에 없음, 모든 USER 화면이 한 곳에 존재).
2. **셸 반영** — `ExcelShell.tsx`의 시트 탭·리본·검색이 새 정의를 따르는지, 모바일 폭 확인.
3. **글 줄이기** — 화면마다 결론 한 줄 먼저, 근거(기간·표본·한계·생성일)는 펼침. 계획 점검 → 돈 흐름 → 시드 만들기 → 포트폴리오 순. 연구 수치 표기 원칙은 유지.
4. **홈 길잡이 정리** — `journey.ts` 다음 할 일 문구를 새 단계 이름에 맞춤.

각 단계 뒤 `pnpm run verify:vercel` + `pnpm --dir web test`. 화면은 사용자가 확인한 뒤 다음 단계로.

## 5. 결정 필요 항목

- 시트 5번째 '더 보기'를 둘지(서랍 열기), 아니면 시트를 4개로 둘지.
- '시장'을 홈 리본 도구로 내려도 되는지(지금은 시트 탭).
- '시드 만들기'를 '모으기' 도구로 내려도 되는지(지금은 시트 탭, 홈에서 자주 쓰는 화면일 수 있음).
- '가족' 탭을 연결 전에도 보일지.

- 데이터 파일(`researchFacts.ts` 등) 수동 수정.
