# 실제 계좌 / 실험 계좌 분리 UX 계획 (2026-10-12)

## 문제

- 같은 "방향"(성향·매달 넣을 돈·버틸 하락폭·손절)이 전체·계좌별·봇 전용으로 네 겹 설정되고, 상속 규칙이 없다.
- 실제 돈 기록(우리 집 수입·지출, 시드 만들기)과 실험(봇 가상계좌)이 서로를 덮어썼다 — 시드 만들기 저장이 가상 월 입금을 바꿨다.
- 포트폴리오 "전체" 탭이 실험과 실제를 한 화면에 섞어 "이도 저도 아닌" 상태가 됐다.

## 원칙

1. **두 세계를 나눈다.**
   - 실제 계좌(내가 증권사에서 직접 매매): 거래 기록·보유 관리·리밸런싱 제안만. 월 입금·자동매매·봇 설정은 없다.
   - 실험 계좌(봇 가상계좌): 월 입금·지수 적립·개별주 몫·자동매매 전부 여기에만. 목적은 "계획을 그대로 따랐다면 어떻게 되나"를 보여 신뢰를 얻는 것.
   - 두 세계의 금액을 한 합계로 더하지 않는다.
2. **방향은 한 번, 한 곳에서.** 첫 진입에서 정하고 바꾸는 곳은 "내 계획" 하나.
3. **실제 계좌는 방향을 물려받고, 계좌마다 고르는 건 사용 시점(오래 둘 돈/날짜 정해진 돈)과 통장 종류뿐.**

## 결정 (2026-10-12, 사용자 위임)

| 항목 | 결정 | 이유 |
|---|---|---|
| 성향 질문 | "버틸 하락폭" 한 질문으로 대체 | 개별주 몫이 10%로 묶여 성향별 전략 선택의 의미가 작다. 하락폭은 비중 상한으로 바로 이어진다(계획 점검 표). |
| 개별주 몫 기본값 | 새 사용자는 "안 함"(지수만), 10%는 선택 | 설정하고 냅두기 방향. 기존 실험 계좌는 지금 설정 유지. |
| 맞벌이 급여일 | 늦은 급여일 다음 날 한 번에 | 숫자 하나·날짜 하나로 단순하게. |
| 실험 계좌 직접 개입 | 일반 화면에선 숨기고 "직접 개입(실험 기록에 남음)" 접힌 메뉴로 | 개입은 서버에 기록되지만 기본 동선에서 실험을 오염시키지 않게. |

## 화면

### 첫 진입(시작 마법사 3단계)
1. 우리 집 돈 흐름: 수입·급여일·지출 → 남는 돈(참고값)
2. 버틸 하락폭 → 주식 비중 상한
3. 내 계획: 매달 투자할 돈(남는 돈 절반 제안)·넣는 날(급여일 다음 날)·처음 넣을 돈·개별주 몫(안 함/10%) → "실험 계좌가 이 계획을 똑같이 따라 합니다"

### 홈 "내 계획" 카드 — 방향을 바꾸는 유일한 곳
`매달 26일 100만원 · 주식 70% · 개별주 안 함 [바꾸기]`, 실험 계좌의 이번 달 입금 상태.

### 포트폴리오
- 상단을 `내 계좌(실제)` / `실험 계좌` 두 갈래로. "전체" 합산 탭 제거.
- 실제 계좌: 기록·리밸런싱 제안. 계좌 정책 카드(성향·손절·종목 수)는 관리자 셸로.
- 실험 계좌: 봇 보유·결과·지수만 했을 때 비교. 추가매수/매도/수정/삭제는 접힌 "직접 개입" 안으로.

### 시드 만들기·돈 흐름
실제 돈 기록만. 실험 계좌 월 입금은 보여주기만(1단계 완료).

### 설정
월 입금액·입금일·전략 모드는 "내 계획"으로 흡수. 알림·계정 연결만 남김.

## 단계

1. ✅ 시드 만들기 ↔ 실험 계좌 월 입금 양방향 동기화 끊기
2. "내 계획" 저장 경로 하나로(서버 prefs 한 묶음: 월 금액·급여일 파생 입금일·하락폭·개별주 몫 → 실험 계좌 입금·전략 모드로 반영)
3. 홈 "내 계획" 카드 + 설정에서 해당 항목 이동
4. 포트폴리오 실제/실험 분리, 실험 계좌 직접 개입 접기
5. 계좌 정책 카드 → 관리자 셸, 실제 계좌는 사용 시점·통장 종류만
6. 시작 마법사 3단계(하락폭 질문)

각 단계 커밋 후 화면 확인을 받고 다음으로 간다.
