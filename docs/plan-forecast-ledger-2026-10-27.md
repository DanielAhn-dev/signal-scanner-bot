# 예측 장부 설계 (2026-10-27)

> 상태: 설계. 코드·DB 변경 없음. 가설 번호는 H69(등록부 최신이 H68).
> 11/23 전에는 새 매매 규칙을 확정하지 않는다 → 1단계(기록·채점)는 규칙이 아니라 **측정**이므로 지금 시작해도 된다. 비중 연결은 11/23 이후.

## 1. 하려는 것과 하지 않을 것

- 하려는 것: "앞으로 시장이 크게 빠질 확률"을 **미리 숫자로 적어 두고**, 결과가 나오면 채점해서, 그 예측이 기준선보다 실제로 나은지 확인한다. 나을 때만 비중 조절의 근거로 쓴다.
- 하지 않을 것: 상승/하락을 맞히는 단일 예측, 예측을 보며 모델을 계속 고쳐 맞추기, 레버리지·전량 이동.

## 2. 이미 아는 것 (중복 방지)

| 기존 결과 | 의미 |
|---|---|
| H42/H44 하락 전 징후 | 2005~ 큰 하락 8번 중 4번만 예고, 독립 사건 4건이라 보류 |
| C55~C60 | 외국인 수급·신용·반대매매·경기선행·연기금 단독으로는 기각 |
| C66 역변동성 비중 | **통과** — 방향 말고 변동성은 어느 정도 예측됨 |

시사점: 방향보다 **낙폭·변동성 위험**을 예측 대상으로 삼고, 기준선을 "변동성 군집만 쓰는 단순 모델"로 잡아야 한다. 낙폭 확률의 대부분은 "최근 변동성이 크다"로 설명되기 때문에, 평균 확률만 이기는 것은 의미가 없다.

## 3. 예측 대상 (사전 고정)

주 대상 하나만 판정에 쓰고, 나머지는 기술 통계로만 기록한다.

| 구분 | 정의 | 용도 |
|---|---|---|
| **T1 (주)** | 이후 20거래일 안에 코스피가 기준일 종가 대비 **−7% 이하**로 내려간 적이 있는가 | 판정 |
| T2 | 이후 20거래일 실현변동성이 직전 250일 분포의 상위 20%인가 | 기술 |
| T3 | 이후 60거래일 수익률이 음수인가 | 기술 |

- 기준일 = 매주 금요일(휴장이면 직전 거래일) 종가. 시각 의존 로직 금지 원칙에 맞춰 종가 확정 후 배치에서 계산.
- 결과 확정은 20거래일 뒤(T3는 60거래일 뒤).
- −7%는 기존 H29 정의와 맞춘 값. 결과를 보고 바꾸지 않는다.

## 4. 모델과 기준선

**후보 모델 M1**: L2 정규화 로지스틱 회귀 1개. 입력은 아래 8개로 고정(추가·삭제 금지, 바꾸면 M2로 새 버전).

| # | 특징 | 출처(캐시) | 시작 |
|---|---|---|---|
| 1 | 20일 실현변동성의 과거 250일 백분위 | kospi.json | 1996 |
| 2 | VKOSPI 5일 평균 / 60일 평균 | vkospi.json | 2003 |
| 3 | 코스피 / 200일선 | kospi.json | 1996 |
| 4 | 120일 고점 대비 거리 | kospi.json | 1996 |
| 5 | 외국인 20일 누적 순매수의 250일 백분위 | kospi_investor_flow.json | 2004 |
| 6 | 신용잔고 60일 변화율 | freesis_credit.json | 1998 |
| 7 | 원/달러 20일 변화율 | longrun/krw_usd_ecos.json | 1996 |
| 8 | 미국 VIX 수준(10년물 금리 변화는 판정 모델에 넣지 않고 기술용으로만 기록) | yh_VIX_daily.json | 1990 |

- 모든 특징은 기준일 종가까지의 정보만 사용. 수급·신용처럼 발표가 늦는 값은 **실제 확정 시각 이후 값만** 쓴다(하루 지연 적용).
- 표준화는 학습 구간 통계만 사용.

**기준선 (이것을 이겨야 함)**

- B0: 학습 구간 전체의 T1 발생 비율(상수 확률).
- **B1: 특징 1(실현변동성 백분위)만 쓴 5구간 비율표.** 진짜 비교 대상. 변동성 군집만으로 설명되는 부분을 제거하기 위함.
- B2: 직전 4주 안에 −5% 이상 빠졌으면 높은 확률, 아니면 낮은 확률(단순 규칙).

## 5. 과거 데이터 재생(백필) — 표본 부족을 메우는 방법

데이터 수집은 필요 없다(위 표처럼 캐시에 이미 있음). 해야 할 일은 **과거를 미래처럼 재생**하는 것.

- 워크포워드(확장 창): 학습 2005-01~2012-12 → 2013-01부터 매주 예측 → 매년 1월에 재학습.
- **퍼지(purge)**: 학습 표본의 결과 창(20거래일)이 예측일과 겹치면 그 표본은 제외. 이걸 빼면 미래 정보가 새어 들어간다.
- 평가 구간 2013~2026 ≈ 14년, 주 단위 약 700회 예측. 단, 결과 창이 20거래일이라 서로 겹쳐서 **독립 표본은 약 170개**, T1 사건(독립)은 20~30개 수준일 것으로 예상. 이 숫자를 결과표 맨 위에 항상 표시한다.
- 2008 이전(2005~2012)은 학습에만 쓰고 평가에서는 빠지므로, 금융위기는 평가에 못 들어간다. 대신 **역방향 검증**(2013~ 학습 → 2005~2012 평가)도 한 번 돌려 기술로 기록한다. 판정에는 안 쓴다.
- 시대 분할: 평가 구간을 2013~2019 / 2020~2026으로 나눠 각각 확인(국면 의존 점검).
- 지수 수준이 1,000대→7,000대로 달라졌으므로 가격 수준 특징은 쓰지 않고 비율·백분위만 사용(위 표 준수).

### 채점

- Brier 점수, 로그손실, 보정 기울기(예측확률 vs 실제 빈도의 회귀 기울기, 1에 가까울수록 좋음), 신뢰도 곡선(확률 구간별 실제 비율).
- 기준선 대비 **Brier 스킬 = 1 − Brier(M1) / Brier(B1)**. 신뢰구간은 20거래일 블록 부트스트랩(블록 겹침 반영) 1만 회.

## 6. 판정 기준 (결과 보기 전 고정)

백필(과거 재생) 통과 = **모두** 충족:
1. 스킬(vs B1) > 0 이고 블록 부트스트랩 90% 구간 하한 > 0
2. 2013~2019, 2020~2026 두 구간에서 각각 스킬 > 0
3. 보정 기울기가 0.7~1.3
4. 독립 T1 사건이 15건 미만이면 판정하지 않고 **보류**(통과·기각 모두 아님)

기각 = 전체 스킬 ≤ 0 이거나 두 구간 모두 90% 구간이 0을 포함하고 점추정이 음수.

전향(실시간) 통과 = 백필 통과 **그리고** 실시간 장부에서 위 1~3을 같은 기준으로 충족. 실시간은 독립 사건이 쌓이는 속도가 느리므로 **최소 26주 + 독립 사건 5건 이상**일 때 처음 보고, 사건이 8건 미만이면 계속 보류. 이 숫자는 과거 평균 빈도로 `validate_forward_test_power.py` 방식의 검정력 계산을 해 본 뒤 그 결과로만 조정한다(조정 이력은 등록부에 남김).

## 7. 실시간 장부

- 테이블 `forecast_ledger`(다음 마이그레이션 번호 040, **사용자가 Supabase에서 직접 실행** 필요). INSERT만 허용, 예측 필드는 수정 불가, 결과 필드만 한 번 채움.

| 컬럼 | 설명 |
|---|---|
| id, made_at, as_of_date | 예측 시각, 기준일 |
| model_version, model_hash | 학습된 계수 해시. 버전 바뀌면 새 장부로 이어서 기록 |
| target | T1/T2/T3 |
| p, p_b0, p_b1, p_b2 | 모델·기준선 확률 (같은 시점에 함께 저장) |
| features jsonb | 입력 특징 스냅샷(재현용) |
| resolve_on, outcome, resolved_at | 확정 예정일, 결과, 확정 시각 |

- 무결성: 예측은 결과 확정 전에 저장되며(`made_at < resolve_on`), 수정·삭제 불가(RLS는 INSERT/조건부 UPDATE만; `using(true)` 쓰기 금지). 기준선도 같은 줄에 저장해서 사후 선택 방지.
- 실행: `daily_data.yml` 뒤에 금요일에만 도는 단계로 붙임(새 워크플로 만들지 않음). 새 Vercel cron 불필요. 휴장·지연이면 다음 거래일에 이월하되 `as_of_date`는 실제 기준일 유지.
- 연 1회 재학습은 사전에 정한 날(1월 첫 금요일), 새 `model_version`으로만. 라이브 결과를 보고 임의로 계수를 바꾸지 않는다.

## 13. H70 사전 등록 — '직전 4주 −5% 하락' 규칙 (결과 보기 전 고정, 2026-10-27)

가설: 기준일 종가가 직전 20거래일 고점 대비 −5% 이하이면, 이후 20거래일 안에 −7% 이하로 내려갈 확률이 아닌 날보다 높고 변동성 기준선(B1)보다도 잘 맞힌다. 이 규칙은 §12에서 코스피 2013~으로 이미 한 번 봤으므로 **그 데이터는 증거로 쓰지 않는다.** 아래 다른 시장·기간에서만 판정한다.

- 규칙·임계값(−5%, 20거래일, −7%)은 고정. 조정 금지.
- 예측 확률 = 학습 구간에서 규칙 켜짐/꺼짐별 −7% 발생 비율(5건 평활화). 기준선은 §4의 B0·B1과 같은 방식(변동성 5구간표).
- 판정 시장(독립 −7% 사건 10건 미만이면 판정에서 제외하고 기술만):
  1. S&P500: 학습 1991~2002 → 2003~ 워크포워드(매년 재학습, 퍼지)
  2. 코스닥: 학습 2002~2009 → 2010~ 워크포워드
  3. 코스피 초기: 학습 2006~ 전체 → 1998~2005 평가(결과 창이 학습 구간과 겹치는 표본 제외)
  4. 나스닥100(2016~): 사건이 적을 것으로 보여 기술 전용
- **통과** = 판정 시장 모두에서 B1 대비 스킬 > 0, 판정 시장 합산 블록 부트스트랩(4주 블록 1만 회) 90% 하한 > 0, B0 대비 합산 스킬 > 0, 각 시장에서 켜짐/꺼짐 발생률 비 ≥ 1.5.
- **기각** = 합산 스킬 ≤ 0 이거나 판정 시장 중 절반 이상에서 B1 대비 스킬 ≤ 0.
- **보류** = 판정 시장이 2곳 미만이거나 위 둘 다 아닐 때.
- 통과해도 하는 일: 기존 하락 안내 카드 문구 후보로만 올린다. 비중 연결은 11/23 이후 별도 사전 등록.
