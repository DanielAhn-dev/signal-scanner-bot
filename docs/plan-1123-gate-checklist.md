# 11/23 관문 일괄 반영 체크리스트 (2026-10-19 작성)

**목적**: 9/28~11/23 전향 기간 동안 "11/23에 보고 정한다"며 미뤄 둔 것을 한곳에 모은다. 11/23에는 이 문서만 위에서부터 따라가며 판정 → 반영 → 기록을 한 번에 끝낸다.
흩어져 있던 출처: `docs/hypothesis-ledger.md`(11/23 반영 관문·안건), `docs/plan-1123-flow-macro-cleanup.md`, 세션 메모(10/07~10/19).

**판정 규칙은 이미 고정돼 있다** (`hypothesis-ledger.md` "11/23 반영 관문", 2026-10-07, 결과 보기 전):
1. 과거 검증 통과(표본 안·밖 모두) 2. 전향 기간 방향이 반대가 아님(유의성 아님, 방향만) 3. 기록 무결성 미해결 없음.
- 손실 차단형 → 조건 만족 시 그대로 넣는다. 수익 추구형 → 가상 계좌 먼저 + 종료 조건. 수익률 비교로만 판단할 것(H1·H2) → 결론 내지 않는다.
- **표본 하한 (2026-10-21 추가, 사용자 결정, 전향 거래 수를 보기 전)**: 규칙이 걸린 전향 거래가 **20건 미만**이면 전향 확인은 '판정 불가' — 손실 차단형은 과거 검증 + 기록 무결성만으로 넣고, 수익 추구형은 다음 관문으로. B 표의 각 항목에서 건수를 먼저 세고 판정한다.
- **이 문서에서 기준을 새로 만들거나 바꾸지 않는다.** 판정 중 기준을 바꾸고 싶어지면 새 가설로 등록하고 다음 관문으로 넘긴다.
