# 투자 아이디어 등록부 (2026-10-07)

**목적**: 새 아이디어를 떠올릴 때마다 처음부터 다시 고민하지 않도록, 이미 검증한 것·적용한 것·아직 안 한 것을 한곳에 모은다.
`hypothesis-ledger.md`는 가설 하나하나의 사전 기준·결과를 적는 장부이고, 이 문서는 **주제별로 찾아보는 색인 + 앞으로 할 후보 목록**이다.

## 새 아이디어가 나오면 (3단계)
1. 아래 **A. 이미 판정한 것**에서 같은 주제를 찾는다. 있으면 결과만 알려 주고 다시 하지 않는다(조건이 다르면 그 차이를 적고 새 가설로 등록).
2. 없으면 **C. 아직 안 한 후보**에 있는지 본다. 있으면 그 우선순위대로 한다.
3. 둘 다 없으면 장부 "후보" 표에 **사전 판정 기준**을 먼저 적고 시작한다. 결과를 본 뒤 기준을 바꾸지 않는다.

공통 원칙(사용자 합의): 개별주 알파는 포기(C1), 레버리지·인버스는 쓰지 않음, 11/23 전에는 새 **매매 규칙**을 넣지 않음(안내·계산 도구는 예외), 유료보다 무료, 신뢰도 우선.

## B. 앱에 적용 중인 것 (이미 반영, 다시 만들지 않기)
- 지수 중심 기본 모드, 정기 적립 자동화, 입금·스윕 로직
- 매수 회피 3종(급등 뒤 5일·한 달 −15%·긴 윗꼬리), 선호 점수 rankBoost ±3, 실적 관문, 50일선 아래 신규 매수 중단
- 비중 조절 경고(과열·변동성) + 시장 외국인 수급 안내
- /plan 계획 점검: 필요 월 적립, 감내 낙폭 비중, 은퇴 인출(건보료·세금 포함), 인컴 점검, 금리 환경, 사용 시점(글라이드 패스), 절세 계좌(세액공제·일반 vs 연금·자산 위치·해외 250만 실현)
- /mix 섞어보기, /choices 내 선택 돌아보기, /start 시작 마법사, /child 자녀 증여 계좌, /income-guide, 보유 카드 종목별 문구
- 가상매매 정합성(RPC 락·중복·가격 검증), 사용자 개입 기록(H16)

## 진행 중 (H1~H17 요약, 상세는 장부)
측정 중: H1 봇 vs 지수, H2 코어 프로필, H3·H4 분기 재검증, H5·H6 경고, H17 선호 점수 / 데이터 대기: H7 뉴스, H8 신용·공매도 / 수집 중: H16 / 보류: H10 PPI.
**11/23 반영 관문**: 과거 검증 통과 + 전향 반대 증거 없음 + 기록 무결성. 손실 차단형은 그대로, 수익 추구형은 가상 계좌 먼저.

## D. 알려진 한계·주의 (아이디어를 다시 평가할 때 필요)
- 한국 표본은 대체로 20~25년, 2025~2026 코스피 3천→9천대 급등이 결과를 좌우함. 미국은 1871~(Shiller)까지 가능.

- 세금·제도 숫자는 여러 자료가 일치하는 선까지만 확인했고 국세청 원문은 직접 확인하지 못했다.
