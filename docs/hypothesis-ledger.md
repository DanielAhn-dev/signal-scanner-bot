# 가설 장부

매매·안내에 영향을 주는 가정을 한곳에 모은다. 원칙:
- **판정 기준은 결과를 보기 전에 적고, 결과를 본 뒤 바꾸지 않는다.** 기준을 바꾸면 새 가설로 다시 등록한다.
- **보정과 튜닝을 구분한다.** 데이터 오류·잘못된 가정의 수정(보정)은 즉시 한다. 결과가 좋아 보이게 파라미터를 바꾸는 것(튜닝)은 하지 않는다.
- **측정 기록 자체를 먼저 의심한다.** 결론을 내기 전에 아래 "기록 무결성"을 확인한다.
