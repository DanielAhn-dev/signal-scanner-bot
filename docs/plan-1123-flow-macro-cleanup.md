# 11/23 일괄 수정 준비: 수급·매크로 근거 정리 (2026-10-15 작성)

**목적**: 2026-10-15 수급·매크로 연구(C55~C58)가 모두 기각돼, 근거 없이 남아 있는 수급·매크로 가감점과 안내 문구를 11/23 관문에서 **한 번에** 고친다. 지금은 손대지 않는다(H1 봇 대 지수 전향 측정을 9/28~11/23 동안 오염시키지 않기 위해, 사용자 결정 2026-10-15).
이 문서만 보고 바로 작업할 수 있도록 위치·변경안·테스트·순서를 적어 둔다. 코드 위치는 2026-10-15 기준이므로 작업 전에 다시 grep으로 확인한다.
